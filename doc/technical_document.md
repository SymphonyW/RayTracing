# 光线追踪渲染器技术文档（增强版）

## 1. 项目概述

本项目基于 [RayTracing/raytracing.github.io](https://github.com/RayTracing/raytracing.github.io.git) 仓库实现，在原有代码基础上新增了 **CPU多线程版本** 和 **GPU版本**，提供更高效的渲染性能。

项目继承了原仓库的三阶段结构：
1. **InOneWeekend** - 基础光线追踪实现
2. **TheNextWeek** - 扩展功能实现
3. **TheRestOfYourLife** - 高级功能实现

## 2. 光线追踪原理

### 2.1 基本概念

光线追踪是一种基于物理的渲染技术，通过模拟光线与物体的交互来生成真实感图像。其基本原理是：

1. **光线发射**：从相机发射光线穿过图像平面的每个像素
2. **光线传播**：光线在场景中传播，与物体相交
3. **光线散射**：光线与物体表面交互，根据材质特性发生反射、折射等现象
4. **颜色计算**：通过累积光线与物体交互产生的颜色，计算最终像素值

### 2.2 路径追踪

本项目实现了路径追踪算法，这是一种蒙特卡洛方法，通过随机采样来模拟光线的多次反弹：

1. 从相机发射主光线
2. 光线与物体相交后，根据材质特性生成新的散射光线
3. 重复上述过程，直到光线逃逸场景或达到最大反弹深度
4. 对每个像素进行多次采样，取平均值以减少噪声

### 2.3 材质模型

项目实现了多种材质模型：

- **漫反射材质**：光线在表面随机散射
- **金属材质**：光线在表面镜面反射，可添加粗糙度
- **电介质材质**：光线在表面发生反射和折射
- **发光材质**：自身发射光线，作为光源

## 4. 核心算法流程

### 4.1 CPU 多线程版本渲染流程
1. 创建场景和相机
2. 确定线程数（默认使用 `std::thread::hardware_concurrency()`）
3. 将像素区域分割成多个块，分配给不同线程
4. 每个线程并行处理分配的像素块：
   - 对每个像素，发射多条采样光线
   - 对每条光线，计算其与场景中物体的交点
   - 根据材质特性，计算光线的散射方向和颜色
   - 重复上述过程，直到光线逃逸或达到最大深度
5. 所有线程完成后，合并结果并输出图像

### 4.2 GPU 版本渲染流程
1. 在 CPU 端创建场景数据
2. 将场景数据复制到 GPU 内存
3. 启动 CUDA 内核，并行处理每个像素
4. 在 GPU 上执行光线追踪计算
5. 将渲染结果从 GPU 内存复制回 CPU
6. 将结果写入图像文件

## 5. 性能优化技术

### 5.1 空间加速结构

项目实现了 BVH（边界体积层次结构）来加速光线与物体的相交测试：

1. **构建 BVH**：递归地将场景物体划分为空间区域
2. **遍历 BVH**：在光线追踪过程中，利用 BVH 快速排除不可能相交的物体
3. **性能提升**：将光线相交测试的时间复杂度从 O(n) 降低到 O(log n)

### 5.2 重要性采样

项目实现了混合 PDF 重要性采样，提高渲染效率：

1. **光源采样**：直接朝向光源发射光线，提高采样效率
2. **余弦采样**：根据表面法线的余弦分布采样，符合物理规律
3. **混合采样**：结合多种采样策略，平衡效率和质量

### 5.3 并行计算优化

#### 5.3.1 CPU 多线程优化
- **任务划分**：将像素区域分割成合适大小的块，避免线程间竞争
- **负载均衡**：确保各线程的工作量大致均衡
- **线程同步**：使用适当的同步机制，避免数据竞争
- **内存访问**：优化内存访问模式，提高缓存利用率

#### 5.3.2 GPU 并行优化
- **线程组织**：合理组织线程块和线程网格，充分利用 GPU 资源
- **内存管理**：优化内存分配和访问模式，减少内存延迟
- **计算密集型操作**：将计算密集型操作移至 GPU 执行
- **内存传输**：减少 CPU 与 GPU 之间的数据传输，仅传输必要的数据

2. **计算密集型操作**：将计算密集型操作移至 GPU 执行
3. **线程协作**：利用 CUDA 的线程协作机制提高效率

## 8. 渲染质量与参数调整

### 8.1 渲染参数

- **分辨率**：影响图像细节和渲染时间
- **每像素采样数**：影响噪声水平和渲染时间
- **最大光线深度**：影响光照真实感和渲染时间
- **相机参数**：影响视角和景深效果
- **线程数**：影响 CPU 多线程版本的渲染速度

### 8.2 质量与性能权衡

| 参数设置 | 渲染质量 | 渲染速度 | 适用场景 |
|---------|---------|---------|--------|
| 低分辨率，低采样率 | 低 | 快 | 预览和调试 |
| 中等分辨率，中等采样率 | 中等 | 中等 | 日常渲染 |
| 高分辨率，高采样率 | 高 | 慢 | 最终输出 |

### 8.3 最佳实践

1. **预览渲染**：使用低分辨率和低采样率快速查看场景效果
2. **最终渲染**：使用高分辨率和高采样率获得最佳质量
3. **参数调整**：根据硬件性能和时间要求调整渲染参数
4. **并行加速**：
   - 对于简单场景，CPU 多线程版本已足够
   - 对于复杂场景，优先使用 GPU 版本获得最佳性能
