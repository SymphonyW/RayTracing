# 光线追踪渲染器技术文档

## 1. 光线追踪原理

### 1.1 基本概念

光线追踪是一种基于物理的渲染技术，通过模拟光线与物体的交互来生成真实感图像。其基本原理是：

1. **光线发射**：从相机发射光线穿过图像平面的每个像素
2. **光线传播**：光线在场景中传播，与物体相交
3. **光线散射**：光线与物体表面交互，根据材质特性发生反射、折射等现象
4. **颜色计算**：通过累积光线与物体交互产生的颜色，计算最终像素值

### 1.2 路径追踪

本项目实现了路径追踪算法，这是一种蒙特卡洛方法，通过随机采样来模拟光线的多次反弹：

1. 从相机发射主光线
2. 光线与物体相交后，根据材质特性生成新的散射光线
3. 重复上述过程，直到光线逃逸场景或达到最大反弹深度
4. 对每个像素进行多次采样，取平均值以减少噪声

### 1.3 材质模型

项目实现了多种材质模型：

- **漫反射材质**：光线在表面随机散射
- **金属材质**：光线在表面镜面反射，可添加粗糙度
- **电介质材质**：光线在表面发生反射和折射
- **发光材质**：自身发射光线，作为光源

### 2.2 核心组件

#### 2.2.1 向量与数学基础
- `vec3.h`：实现了三维向量的基本运算
- `rtweekend.h`：包含数学常量和工具函数
- `interval.h`：区间类，用于光线与物体相交的参数范围

#### 2.2.2 几何与碰撞检测
- `ray.h`：光线类，定义光线的起点和方向
- `hittable.h`：可击中物体的抽象基类
- `hittable_list.h`：物体列表，用于管理场景中的物体
- `sphere.h`：球体类，实现基本的球体几何
- `quad.h`：四边形类，实现平面几何
- `aabb.h`：轴对齐边界盒，用于加速碰撞检测
- `bvh.h`：边界体积层次结构，用于加速场景遍历

#### 2.2.3 材质系统
- `material.h`：材质基类，定义材质的散射行为
- `texture.h`：纹理类，用于实现物体表面的纹理
- `perlin.h`：Perlin噪声生成器，用于创建自然的表面效果

#### 2.2.4 相机系统
- `camera.h`：相机类，实现透视投影和景深效果

#### 2.2.5 高级功能
- `pdf.h`：概率密度函数，用于重要性采样
- `onb.h`：正交基，用于局部坐标系转换
- `constant_medium.h`：体积介质，用于实现烟雾、 fog 等效果

#### 2.2.6 GPU 加速
- `cuda_common.h`：CUDA 公共定义
- `cuda_geometry.h`：GPU 上的几何实现
- `cuda_materials.h`：GPU 上的材质实现
- `main_cuda.cu`：GPU 版本的主入口

### 2.3 核心算法流程

#### 2.3.1 CPU 版本渲染流程
1. 创建场景和相机
2. 对每个像素，发射多条采样光线
3. 对每条光线，计算其与场景中物体的交点
4. 根据材质特性，计算光线的散射方向和颜色
5. 重复步骤 3-4，直到光线逃逸或达到最大深度
6. 对所有采样光线的颜色取平均值，得到最终像素颜色

#### 2.3.2 GPU 版本渲染流程
1. 在 CPU 端创建场景数据
2. 将场景数据复制到 GPU 内存
3. 启动 CUDA 内核，并行处理每个像素
4. 在 GPU 上执行光线追踪计算
5. 将渲染结果从 GPU 内存复制回 CPU
6. 将结果写入图像文件

## 3. 性能优化技术

### 3.1 空间加速结构

项目实现了 BVH（边界体积层次结构）来加速光线与物体的相交测试：

1. **构建 BVH**：递归地将场景物体划分为空间区域
2. **遍历 BVH**：在光线追踪过程中，利用 BVH 快速排除不可能相交的物体
3. **性能提升**：将光线相交测试的时间复杂度从 O(n) 降低到 O(log n)

### 3.2 重要性采样

项目实现了混合 PDF 重要性采样，提高渲染效率：

1. **光源采样**：直接朝向光源发射光线，提高采样效率
2. **余弦采样**：根据表面法线的余弦分布采样，符合物理规律
3. **混合采样**：结合多种采样策略，平衡效率和质量

### 3.3 并行计算

#### 3.3.1 CPU 多线程
- 利用现代 CPU 的多核心特性
- 对像素渲染任务进行并行处理
- 提高 CPU 利用率，减少渲染时间

#### 3.3.2 GPU 并行
- 利用 CUDA 平台的大规模并行计算能力
- 每个像素由一个 CUDA 线程处理
- 显著提升渲染速度，特别是对于高分辨率和高采样率的场景

## 4. GPU 加速实现

### 4.1 CUDA 架构

项目使用 NVIDIA CUDA 平台实现 GPU 加速：

1. **设备内存管理**：合理分配和使用 GPU 内存
2. **并行线程组织**：使用线程块和线程网格组织并行计算
3. **内存访问优化**：优化内存访问模式，减少内存延迟
4. **同步机制**：使用适当的同步机制确保计算正确性

### 4.2 GPU 代码结构

#### 4.2.1 核心内核
- `init_rand_state`：初始化随机数生成器
- `ray_color`：计算光线颜色（使用重要性采样）
- `render_kernel`：主渲染内核，处理每个像素

#### 4.2.2 场景表示
- 在 GPU 上使用紧凑的数据结构表示场景
- 材质、几何形状等数据存储在 GPU 内存中
- 光线与物体的相交测试在 GPU 上高效执行

### 4.3 性能优化

1. **内存传输优化**：减少 CPU 与 GPU 之间的数据传输
2. **计算密集型操作**：将计算密集型操作移至 GPU 执行
3. **线程协作**：利用 CUDA 的线程协作机制提高效率
4. **寄存器使用**：合理使用寄存器，减少全局内存访问

## 6. 渲染质量与参数调整

### 6.1 渲染参数

- **分辨率**：影响图像细节和渲染时间
- **每像素采样数**：影响噪声水平和渲染时间
- **最大光线深度**：影响光照真实感和渲染时间
- **相机参数**：影响视角和景深效果

### 6.2 质量与性能权衡

| 参数设置 | 渲染质量 | 渲染速度 | 适用场景 |
|---------|---------|---------|--------|
| 低分辨率，低采样率 | 低 | 快 | 预览和调试 |
| 中等分辨率，中等采样率 | 中等 | 中等 | 日常渲染 |
| 高分辨率，高采样率 | 高 | 慢 | 最终输出 |

### 6.3 最佳实践

1. **预览渲染**：使用低分辨率和低采样率快速查看场景效果
2. **最终渲染**：使用高分辨率和高采样率获得最佳质量
3. **参数调整**：根据硬件性能和时间要求调整渲染参数
4. **GPU 加速**：对于复杂场景，优先使用 GPU 版本
